# 人物立绘 · Q版国风 IP 插画提示词

统一风格：**Q版国风半身IP插画，半Q版古风人物，头身比例约2.5头身，大眼睛，表情亲和但保留人物气质，
干净线条，低饱和雅致配色，人物居中，半身像，透明PNG背景，无背景杂物，无文字，细腻平涂，
少量柔和渐变，不做复杂阴影，国潮风**。

## 生成与导入规范

1. 每人生成一张，**512×768（宽:高 = 2:3）透明底 PNG**，人物居中半身像、无背景杂物、无文字；
2. 文件名 = 人物 id（见下方表格），覆盖到 `assets/characters/{id}.png`，**代码零改动**；
3. 生成后运行 `python scripts/check_portraits.py` 校验透明度/尺寸/就绪数量；
4. 尺寸不合可用 PIL 处理：`python -c "from PIL import Image; im=Image.open('x.png').convert('RGBA'); im.resize((512,768), Image.LANCZOS).save('assets/characters/{id}.png')"`。
